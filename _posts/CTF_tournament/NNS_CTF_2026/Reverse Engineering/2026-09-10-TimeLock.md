## Description

New to reverse engineering? This beginner challenge is an introduction to
replacing the library functions a Linux program calls, so it sees what you
want it to see.

The provided `x86-64` ELF is a sealed archive. It asks the C standard
library what day it is, refuses to open unless the answer is
1 January 9999, and prints `sealed` every other day of the year. Waiting
is not an option, and neither is changing your system clock.

The dynamic loader lets you put your own shared library in front of libc,
so the program ends up calling your function instead of the real one.
Write a replacement for the call it uses to read the clock, preload it,
and run the program again. Note that patching the date check on its own
will not be enough. The key is derived from the answer the program gets
back, not merely compared against it.

## Walkthrough

I firstly imported the provided file to `pwndbg` to see its functions:

```bash
pwndbg> info functions
All defined functions:

Non-debugging symbols:
0x0000000000401010  _exit@plt
0x0000000000401020  write@plt
0x0000000000401030  time@plt
0x0000000000401040  _start
```

The `time` API should return the value corresponding to 1 January 9999, so that the flag can appear. 

The technique to solve this challenge is called `ELF symbol interposition`.

> "ELF symbol interposition is a feature of the Executable and Linkable Format (ELF) dynamic linking model where a function or variable definition in one shared object or executable overrides or replaces a definition of the same name in another loaded library"

> ---Google Gemini---

Let's create our own `time` function. The first thing you wanna do here is to read the definition of the real API.

Run `man 2 time` in your Linux terminal:

```bash
time(2)                                                      System Calls Manual                                                     time(2)

NAME
       time - get time in seconds

LIBRARY
       Standard C library (libc, -lc)

SYNOPSIS
       #include <time.h>

       time_t time(time_t *_Nullable tloc);

DESCRIPTION
       time() returns the time as the number of seconds since the Epoch, 1970-01-01 00:00:00 +0000 (UTC).

       If tloc is non-NULL, the return value is also stored in the memory pointed to by tloc.
```

So we need to know the number of seconds since the Epoch of 1 Jan 9999. [EpochConverter](https://www.epochconverter.com/) supports us in this stage.

![1](</assets/img/CTF_tournament/NNS CTF 2026/Time Lock/1.jpg>)

The value is `253370764800`.

Recreating the function requires the exact declaration of the real one:

```c
#define GNU_SOURCE
#include <time.h>

time_t time(time_t* ptr) {
    time_t fake_time = (time_t)253370764800LL;

    return fake_time;
}
```

Compile it via GCC:

```bash
gcc -shared -fPIC -o faketime.so faketime.c
```

- `-shared`

Output a [Shared Library](https://en.wikipedia.org/wiki/Shared_library) file (`.so`).

- `-fPIC`

Compile our source code to [Position-Independent Code (PIC)](https://en.wikipedia.org/wiki/Position-independent_code)

When done, run `time-lock` with our newly created library:

```bash
TZ=UTC LD_PRELOAD="$PWD/faketime.so" ./time-lock
```

- `TZ=UTC`

This specifies the time zone when running.

- `LD_PRELOAD="$PWD/faketime.so"`

`LD_PRELOAD` is used to ask the dynamic loader to import one or more libraries **before** other ordinary libraries.

Result:

```bash
❯ TZ=UTC LD_PRELOAD="$PWD/faketime.so" ./time-lock
NNS{y0u_c4n_l13_70_4_pr0gr4m_w17h_ld_pr3l04d}
```
